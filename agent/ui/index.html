How to Use

PrintBridge runs in the background and listens for print requests from web applications. Install the SDK in your web app and connect to ws://localhost:9718.

About

PrintBridge is an open-source solution for printing from web applications. It enables batch printing, raw printing (ESC/POS, ZPL), and more without browser dialogs or certificate management.
